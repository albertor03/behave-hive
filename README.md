# behave-hive

A layer on top of [behave](https://github.com/behave/behave) that adds:

- **CSV Examples:** Karate-style data files for `Scenario Outline` (`| read('data/users.csv') |`).
- **Sequential or parallel runs:** configured in `behave.ini`.
- **Consolidated reports:** Allure, Cucumber JSON and HTML.

> Work in progress. Full documentation will be added before the first release.
